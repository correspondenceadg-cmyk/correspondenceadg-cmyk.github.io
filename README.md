# # Your Store Name Here

A single-file HTML/CSS/JavaScript demo storefront with a retro-futuristic wasteland/space theme.

## Features
- Responsive product grid with 10 sample items
- Hamburger slide-out menu and client-side page switching
- Pages: Home, Cart, Ordering Info, My Account, Contact
- Mock order tracking (`WST-12345`, `WST-67890`, `DEMO-001`)
- Animated starfield, parallax scrolling, twinkling stars, and sparkle bursts
- Crescent moon and animated shop banner

## Run
1. Save the file as `index.html`.
2. Open it in a modern web browser.

No build tools or dependencies required.

## Customize
- Edit the `productNames` array to change products.
- Update menu links and placeholder text in each `.page`.
- Modify the mock order statuses in the tracking script.

## Notes
- This is a front-end demo; cart, account, and ordering pages are placeholders.
- Right-click/devtools blocking is included but is not real security.
